# v0.9.4.8 source release · October 2026

The latest complete Gateway source is [versions/v0.9.4.8](../versions/v0.9.4.8/README.md).
It is drawn from the October 13 full-fusion runtime snapshot, as identified by the
October 14 archive overview. Earlier version directories and the original minimal
R1 package remain historical, separate implementations. The R1 package version
`1.0.0` is not the industrial Gateway version.

The October profile uses D12's own three-part action Memo and three independent
read-only reviews. D16 supplies a minimal implementation delta, D9 a worthwhile
alternative and D13 a state consistency check. Each sees the same selected packet;
none executes tools or sees the parallel opinions. D12 retains the full effective
execution record and alone returns final text or native tool calls. Advice is
revisable and has no vote or veto. This proposal-review branch uses text opinions,
not the typed packet/ID selection/Integrator machinery retained in legacy modules.

The default publication launcher selects `initial_panel + proposal_review`.
Subsequent requests consult only through existing conditional recall or explicit
controls. Memo and reviews share a 120-second absolute budget; the collector waits
for all reviews or that deadline. Partial reviews completed by the deadline
are valid inputs; zero reviews retain a valid Memo. An unavailable Memo or advice
context failure lets D12 continue on its normal context. Compact, Soft Stall,
Hard/Exact/Result Cycle, episode reuse, system-first Recovery, `length` lifecycle
handling, native tool output, streaming and normalization remain in the complete
runtime. D12-only preserves managed execution and Recovery while disabling
collaboration and auxiliary Compact, so it must not be labelled a bare-model test.

External agents own task loops, tools and official scoring. Source publication
does not restart a model, switch production routing or rerun an experiment. Fixed
budget first-pass results and retained coverage across longer attempts must be
reported separately; retained coverage cannot identify an individual expert's
causal contribution. The public aggregate evidence is supplied separately from
the runtime and excludes task instructions and trajectories.

The publication allowlist includes the complete first-party runtime modules and
schema, current profiles, the compatible Claude bridge, local-only configuration
templates and portable launchers. It excludes credentials, private host names/IPs,
personal home paths, hardware deployment inventories, task data, raw logs/wire,
trajectories, model weights, Docker exports and third-party inference engine
sources. Benchmark publication is limited to aggregate result tables and
evaluation conditions in README files; per-task records, audit artifacts and
internal source inventories remain private. Runtime traces generated after
deployment are local artifacts and ignored by Git.

No new dependency family or license was selected. The historical
[v0.9.4.5 candidate note](v0.9.4.5-candidate.md) describes that earlier publication,
not the current version. See the new package README for launch, task ID, bridge,
control-mode and offline-verification instructions.
